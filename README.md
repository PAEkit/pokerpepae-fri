# PokerPEPAE&Fri ♠♥♦♣

เท็กซัสโฮลเดม (ชิปสมมติ) เล่นกับเพื่อนคนละที่ผ่านอินเทอร์เน็ต ใช้งานบน iPhone ผ่าน Safari ได้เลย ไม่ต้องมี Mac ไม่ต้องจ่ายค่า Apple Developer

- เพื่อนเข้าห้องด้วยรหัส 4 ตัวอักษร กดลิงก์เชิญ หรือเลือกจาก "รายการห้องที่ออนไลน์อยู่" ในหน้าแรก (ติ๊ก "ห้องส่วนตัว" ตอนสร้างห้องถ้าไม่อยากให้โชว์ในรายการ)
- จบตาแล้วพัก 10 วินาทีก่อนตาถัดไป, มีพลุฉลองที่ที่นั่งผู้ชนะทุกตา
- เมื่อทุกคนออลอิน ระบบเปิดไพ่ในมือให้เห็น แล้วเปิดไพ่กลางทีละใบเว้นจังหวะให้ลุ้น
- ไม่มี "เริ่มเกมใหม่": เมื่อเหลือคนมีชิปคนเดียว โต๊ะจะหยุดรอ พอมีคนกดซื้อชิป (บายอิน) จนมีชิป 2 คนขึ้นไป เกมเดินต่อเองและชิปคนอื่นไม่ถูกรีเซ็ต
- มีโหมดผู้ชม ดูโต๊ะได้อย่างเดียว ไม่เห็นไพ่ใคร กดอะไรไม่ได้ และกด "เข้าร่วมเล่น" เมื่อมีที่ว่างได้
- กดไอคอน 🪙 ดูยอดบายอินรวม กราฟชิปรายตาของทุกคน และสถิติ 💀 (จำนวนครั้งที่ทำให้คนอื่นชิปเหลือ 0) · ไอคอน 💬 แชท/ประวัติอยู่มุมล่างขวาของโต๊ะ · มีป้าย D / SB / BB ที่โปรไฟล์
- ปุ่มเรส: ปรับทีละเท่า Small Blind, ปุ่มเพิ่ม +SB +BB +2BB +3BB, ล้าง (กลับค่าต่ำสุด), ออลอิน และค่าเรสกลับเป็นต่ำสุดทุกครั้งที่ถึงตา
- เอฟเฟกต์: ชิปไหลจากที่นั่งมาวางหน้าที่นั่ง → รวมเข้ากอง Pot → ไหลไปหาผู้ชนะ, ป้าย ALL-IN, กองชิปที่ Pot, มงกุฎทองผู้ชนะ, แจกไพ่ตอนเริ่มตา, เลขนับถอยหลังไฮไลท์, เปิดเทิร์น/ริเวอร์ช้าลงตอนฟลิปสู้
- 🔊 เสียง: เพลงพื้นหลังสบายๆ (สร้างเสียงเองในเครื่อง ไม่มีไฟล์เพลง), เสียงเอฟเฟกต์ทุกปุ่ม/ไพ่/ชิป, เสียงเตือนเมื่อถึงตา — ปุ่ม 🔊 เปิดปิดและปรับวอลุ่มแยกเพลง / เอฟเฟกต์ / เสียงไมค์เพื่อน (บน iPhone ต้องปิดโหมดเงียบด้วย)
- 🏆 ทัวร์นาเมนต์ (เลือกตอนสร้างห้อง): บายอิน ฿ → ชิป (฿1 = 10 ชิป, ค่าเริ่มต้น 100฿ = 1,000 ชิป), บลายด์ 10/20 เพิ่ม 2 เท่าทุก 10 ตา, บายอินเพิ่มได้คนละ 2 ครั้งภายใน 5 ตาหลังชิปหมด, เหลือ 3 คนสุดท้ายปิดบายอินและคนชิปหมดตกรอบเป็นผู้ชมทันที, เริ่มแล้วไม่รับผู้เล่นเพิ่ม, จบแล้วแบ่งรางวัล 60/30/10% ปัดหลัก 100฿ (อันดับ 1 รับส่วนที่เหลือเพื่อให้ยอดรวมตรง) และบันทึกประวัติไว้ในเครื่อง (ไอคอน 🏆 หน้าแรก)
- 💬 แชทในล็อบบี้ (ผู้ชมแชทได้), ไอคอนแชร์ข้างรหัสห้อง, ไอคอนสมาชิกในห้อง 👥 และปุ่มออกจากห้องแยกอยู่ขวาสุด, เสียงเตือนถึงตาแยกปรับเสียงได้, เพลง BGM จังหวะบอสซ่า
- 🏆 Tournament: หน้าต่างกติกาตอนเข้าล็อบบี้, โต๊ะสีน้ำเงิน + ลายน้ำ TOURNAMENT #เลข, ปุ่ม 💰 ซ้ายล่างดูสถานะบายอิน/เงินรางวัล, อันดับ 4 ที่ชิปหมดยังบายอินได้ (ปิดเมื่อเหลือ 3 คนสุดท้าย)
- 🔔 Tournament: แจ้งเตือนเมื่อบลายด์เพิ่ม (เตือนล่วงหน้า 1 ตา + ประกาศตอนเพิ่มจริง), สรุปผลมีส่วนต่าง (เงินรางวัล − บายอิน), สติกเกอร์ 24 แบบแบบ cut-out
- 🔀 สับที่นั่งทุก 15 ตา: ไพ่ A,2,3… คว่ำกลางโต๊ะ ทุกคนแตะเลือกคนละใบ ใบสูงสุด = BB, รองลงมา = SB, ใบ A = D
- 😊 สติกเกอร์อารมณ์: ปุ่มเล็กมุมซ้ายล่างของโต๊ะ (5 อันแรกเป็นรูป+เสียงที่ผู้ใช้ให้มา อยู่ใน `public/stickers/` เพิ่มอันใหม่ได้โดยใส่ไฟล์แล้วเติมรายการ STK ใน index.html; ที่เหลือเป็นภาพวาดต้นฉบับ มีเสียงเล่นให้ทุกคนในห้องตอนมีคนใช้)
- ✔ ปุ่มเช็ค/โฟลด์ล่วงหน้า, 👁 ปุ่มโชว์ไพ่หลังจบตา, 👁 รายชื่อผู้ชม (ปุ่มด้านบน), ไฟแดงที่ผู้เล่นซึ่งไพ่นำอยู่ตอนลุ้นไพ่
- 🎤 ห้องเสียง: กดปุ่ม 🎤 ด้านบนเพื่อเข้าไปพูดคุยกัน (ไมค์ปิดไว้จนกว่าจะกดเข้า, กดอีกครั้งเพื่อปิด/เปิดไมค์, ที่นั่งคนพูดจะเรืองสีเขียว, ปิดเสียงรายคนได้ในเมนู 🏠, ผู้ชมพูดได้เหมือนกัน) แนะนำให้ใส่หูฟัง
- 2–9 คนต่อห้อง, บลายด์/ชิปเริ่มต้น/เวลาต่อตา ตั้งได้ตอนสร้างห้อง
- มีไซด์พ็อต, ออลอิน, ซื้อชิปเพิ่มเมื่อหมด, แชท/อิโมจิ, สั่นเมื่อถึงตา (Android)
- คนหลุดเน็ตหรือหมดเวลา ระบบเช็ค/โฟลด์ให้เอง ตาจะไม่ค้าง
- เซิร์ฟเวอร์เป็นคนแจกไพ่และคุมกติกาทั้งหมด ไพ่ของคนอื่นจะไม่ถูกส่งไปยังเครื่องของคุณจนกว่าจะเปิดไพ่

## ขั้นตอนเอาขึ้นออนไลน์ (ทำครั้งเดียว ประมาณ 10 นาที)

### 1) เอาโค้ดขึ้น GitHub
1. สมัคร/ล็อกอิน <https://github.com>
2. กด **New repository** ตั้งชื่อ `pokerpepae-fri` เลือก **Private** (หรือ Public ก็ได้) แล้วกด Create
3. ในหน้า repo กด **uploading an existing file** แล้วลากไฟล์ทั้งหมดในโฟลเดอร์ `pokerpepae-fri` (หลังแตก zip) เข้าไป
   ต้องลากทั้ง `server.js`, `package.json`, `render.yaml`, โฟลเดอร์ `lib`, `public`, `test` ให้โครงสร้างโฟลเดอร์ครบ
4. กด **Commit changes**

### 2) สร้างเว็บบน Render
1. สมัคร/ล็อกอิน <https://render.com> (เลือก Sign in with GitHub จะง่ายที่สุด)
2. กด **New +** → **Web Service** → เลือก repo `pokerpepae-fri`
3. ตั้งค่าตามนี้
   - **Runtime / Language:** Node
   - **Build Command:** `echo ok` (ไม่มีอะไรต้อง build เพราะไม่มีแพ็กเกจเสริม)
   - **Start Command:** `node server.js`
   - **Instance Type:** Free
4. กด **Create Web Service** รอจนขึ้นว่า Live แล้วจะได้ลิงก์ประมาณ `https://pokerpepae-fri-xxxx.onrender.com`

### 3) เล่นบน iPhone
1. เปิดลิงก์ด้วย **Safari**
2. กดปุ่มแชร์ (สี่เหลี่ยมมีลูกศรขึ้น) → **เพิ่มไปยังหน้าจอโฮม** จะได้ไอคอน PokerPEPAE&Fri เปิดเต็มจอเหมือนแอพ
3. ใส่ชื่อ → **สร้างห้อง** → กด **ส่งลิงก์ให้เพื่อน** → เพื่อนกดลิงก์ ใส่ชื่อ → เข้าร่วม
4. เจ้าของห้องกด **เริ่มเกม** เมื่อครบคน

## ข้อควรรู้

- **แพ็กเกจฟรีของ Render จะหลับเมื่อไม่มีคนใช้สักพัก** การเปิดลิงก์ครั้งแรกหลังหลับอาจรอ 30–60 วินาที ให้ทุกคนเปิดลิงก์ก่อนเริ่มเล่นสักครู่ เงื่อนไขของแพ็กเกจฟรีอาจเปลี่ยนได้ ลองดูหน้าราคาของ Render อีกครั้งตอนสมัคร
- **ห้องเก็บอยู่ในหน่วยความจำของเซิร์ฟเวอร์** ถ้าเซิร์ฟเวอร์หลับยาวหรือรีสตาร์ท ห้องและชิปจะหายหมด ต้องสร้างห้องใหม่ (เหมาะกับเล่นขำๆ รายคืน)
- ถ้าหลุดเน็ตกลางเกม เปิดแอพใหม่ได้เลย จะกลับมานั่งที่เดิมพร้อมชิปเดิม (จำไว้ในเครื่องด้วย token)
- ถ้าหน้าจอ iPhone ล็อก เครื่องจะตัดการเชื่อมต่อ เปิดจอแล้วจะเชื่อมต่อใหม่เอง ถ้าถึงตาตอนจอดับ ระบบจะรอตามเวลาที่ตั้งแล้วเช็ค/โฟลด์ให้

- **เสียงพูด** ส่งตรงระหว่างเครื่อง (WebRTC) ต้องเปิดผ่าน https (Render ให้อยู่แล้ว) และกดอนุญาตไมค์ ถ้าบางคนต่อเสียงกันไม่ได้ (เช่น เน็ตมือถือบางเจ้า) ให้ตั้ง TURN server ของผู้ให้บริการ แล้วใส่ใน Environment ของ Render ชื่อ `ICE_SERVERS` เป็น JSON เช่น `[{"urls":"turn:host:3478","username":"u","credential":"p"}]`
- อัปโหลดโค้ดใหม่ขึ้น GitHub แล้ว Render รีสตาร์ท ห้องที่เล่นอยู่จะหายหมด

## กติกาที่ใช้ (สรุป)

- เท็กซัสโฮลเดม แจกไพ่ 2 ใบ, ฟลอป/เทิร์น/ริเวอร์, ปุ่มดีลเลอร์เลื่อนทุกตา
- เฮดส์อัพ (2 คน) ดีลเลอร์เป็น Small Blind และเล่นก่อนในพรีฟลอป
- เรสขั้นต่ำเท่ากับขนาดเรสครั้งก่อน (หรือบิ๊กบลายด์)
- ออลอินน้อยกว่าขั้นต่ำถือว่าเปิดให้ทุกคนตัดสินใจใหม่ได้อีกรอบ (ง่ายกว่ากติกาคาสิโนเล็กน้อย)
- ส่วนที่ไม่มีใครคอลจะถูกคืนเจ้าของ, มีไซด์พ็อตเมื่อมีคนออลอินด้วยชิปไม่เท่ากัน
- เสมอกันหารพ็อต เศษชิปให้คนที่นั่งซ้ายมือดีลเลอร์ก่อน

## โครงสร้างโปรเจกต์

```
server.js          เซิร์ฟเวอร์ HTTP + Server-Sent Events (ไม่มี dependency)
lib/hands.js       ตัวจัดอันดับมือไพ่
lib/game.js        เอนจินเกม (เดิมพัน, ไซด์พ็อต, ตา, ไทเมอร์)
public/            หน้าเว็บ (index.html), ไอคอน, manifest
test/              ทดสอบกติกา + เซิร์ฟเวอร์
```

ชิปทั้งหมดเป็นชิปสมมติเพื่อความสนุกเท่านั้น
