โฟลเดอร์ตัวเลือกเสียงของเกม
- card.js : เสียงเปิดไพ่ (คลาสสิก / ปึ้บ / รูด / ติ๊ง / ปิด)
- bgm.js  : เพลงพื้นหลัง (บอสซ่าสดใส / ชิลล์ / สนุกสนาน / กล่องดนตรี)
เสียงทั้งหมดสร้างสดในเครื่อง ไม่ต้องมีไฟล์เสียง อยากเพิ่มแบบใหม่ ให้เติมรายการต่อท้ายอาร์เรย์ในไฟล์เหล่านี้
ผู้เล่นเลือกได้ที่ไอคอน 🔊 (ตั้งค่าเสียง) กดแต่ละอันเพื่อฟังตัวอย่าง
